# Security Policy for AGEWELL

## Supported Versions

We actively support and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## Reporting a Vulnerability

The AGEWELL team takes senior patient data privacy and emergency infrastructure security seriously.

If you believe you have discovered a security vulnerability in AGEWELL:
1. **Do not disclose the issue publicly** on GitHub Issues or community forums.
2. Email the maintainers directly at `security@agewell.com` or contact `ARIPRAKASH32` via GitHub.
3. Provide detailed steps to reproduce the vulnerability, including any relevant payloads, endpoints, or environment conditions.

### Response Timeline
- **Acknowledgement**: Within 48 hours of report submission.
- **Triage & Remediation**: Critical issues addressed within 7 business days.
- **Public Disclosure**: Coordinated after a fix is merged to `main`.
